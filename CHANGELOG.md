# Changelog

All notable changes follow Keep a Changelog and Semantic Versioning.

## [0.2.0] - 2026-07-25

### Added

- A product-led landing page with four live, deterministic system previews.
- Responsive desktop and mobile compositions, quick-start code, workflow, and
  direct Studio and catalog paths.

### Changed

- Moved the full 40-system laboratory to `catalog.html` so discovery and
  technical inspection have distinct surfaces.

## [0.1.0] - 2026-07-25

### Added

- Public `createAsset()` and `mount()` API.
- Auto-registering `<living-asset>` Web Component.
- Twelve validated, deterministic presets.
- Forty generative modules, Studio MP4/WebM export, LivingStory, examples, and
  the WordPress integration.
- Tests, type checking, packaging checks, and GitHub Actions.

### Changed

- Unified the public product and package name as Living Interfaces.
- Removed the unused GSAP dependency and vendored file.
