# Roadmap

## 0.1 — Choose, customize, embed, or export

- Stable public API, Web Component, presets, Studio, docs, and WordPress ZIP.

## 0.2 — Creator workflow

- Import/export `.living.json` projects.
- Shareable setup URLs.
- Text and logo layers.
- Audio-reactive and WebSocket data inputs.
- Multi-size export presets.

## 0.3 — Contributor SDK

- Asset scaffolding and validation CLI.
- Community preset format and gallery.
- Performance and lifecycle budgets.

Roadmap items are intentions, not compatibility promises. Proposals should
start as focused GitHub issues before implementation.
