# Security policy

The latest release receives security fixes.

Do not open a public issue for a vulnerability. Use GitHub's private
vulnerability reporting for this repository and include:

- the affected version and browser;
- impact and reproduction steps;
- a minimal proof of concept when safe;
- any suggested mitigation.

Avoid including secrets, personal data, or active exploit traffic. We will
acknowledge a complete report as soon as practical and coordinate disclosure
after a fix is available.
